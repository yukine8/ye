# ye

シンプルで、高速で、大量のブックマークを置けて、同期ができる新しいタブ

# 使い方

### 新しいタブの編集

**この拡張機能に編集機能はありません。**

ブラウザの標準のブックマーク管理機能で、以下のフォルダを編集してください

- Chrome: `その他のブックマーク` > `ye`

- Firefox: `他のブックマーク` > `ye`

### 同期

ブラウザ標準の同期機能を利用します

異なるブラウザで同期したい場合は、[flocuss](https://floccus.org/) 等の外部ツールを併用してください

# 開発環境

### formatter の担当

- `Prettier`: HTML, Markdown

- `Biome`: CSS, JavaScript

### セットアップ

npm や pnpm で `Biome` を入れる

```bash
pnpm add --save-dev --save-exact @biomejs/biome
```

VSCode で `Prettier` と `Biome` をいれる
